تطبيق Windows بسيط للتبديل بين حسابات أو إعدادات مواقع API المحفوظة في
Codex وClaude Code وOpenCode.

لا يغيّر إلا معلومات الحساب وإعدادات API المدعومة المحفوظة في ملف التعريف.
تبقى خوادم MCP والمهارات والإضافات وإعدادات المشاريع والسجل في أماكنها.

> [!IMPORTANT]
> هذا مشروع مجتمعي غير رسمي، ولا يتبع OpenAI أو Anthropic أو Apple أو مشروع
> OpenCode. لا ينقل الاشتراكات ولا يتجاوز متطلبات تسجيل الدخول أو سياسات المؤسسة.

## التنزيل

احصل على الإصدار الحالي من
[أحدث إصدار](https://github.com/zzz1999/coding-agent-account-switcher/releases/latest):

- **المثبّت:** <code>coding-agent-account-switcher-setup-win-x64.exe</code>
- **التطبيق المحمول:** <code>coding-agent-account-switcher-portable-win-x64.exe</code>
- **ملفات التحقق:** يتوفر ملف SHA-256 مطابق لكل ملف تنفيذي

يُثبّت التطبيق للمستخدم الحالي فقط، ولا يحتاج إلى صلاحيات المسؤول، ولا يفعّل
**البدء مع Windows** دون اختيارك. الإصدارات الحالية غير موقّعة، لذلك قد يعرض
Windows SmartScreen تحذيراً.

## الميزات الرئيسية

- احفظ ملفات شخصية وللعمل ولمواقع API بأسماء واضحة.
- بدّل حسابات Codex وClaude Code وOpenCode ببضع نقرات.
- احتفظ بعناوين API ومفاتيحها ومزوديها ونماذجها المدعومة مع الملف الصحيح.
- أعد تسمية ملف بالنقر المزدوج أو احذف لقطة محلية.
- شاهد تأكيداً واضحاً لاسم الملف النشط بعد التبديل.
- امنع التبديل ما دامت التطبيقات المرتبطة مفتوحة.
- استخدم واحدة من 12 لغة مدمجة.
- احتفظ بالمظهر الفاتح أو الداكن واللغة بين مرات التشغيل.
- شغّل التطبيق اختيارياً مع Windows وتحقق من التحديثات يدوياً.

تبقى جميع البيانات على الكمبيوتر. لا يحتوي التطبيق على تحليلات أو قياس عن بُعد.

## التطبيقات المدعومة

| التطبيق | ما يتم تبديله | ما يبقى دون تغيير |
| --- | --- | --- |
| Codex | تسجيل الدخول وإعدادات مزود/نموذج API المدعومة | MCP والمهارات والجلسات والسجل والإعدادات الأخرى |
| Claude Code | تسجيل الدخول وإعدادات عنوان/مفتاح API المدعومة | الإضافات وMCP والمشاريع والسجل والإعدادات الأخرى |
| OpenCode | تسجيل الدخول المحفوظ وإعدادات المزود/النموذج المدعومة | إعدادات المشروع والإعدادات الأخرى |

لا تتغير إلا حقول الحساب التي يدعمها المشروع. راجع
[وثيقة البنية](docs/ARCHITECTURE.md) للاطلاع على القائمة الدقيقة.

## بدء سريع

1. سجّل الدخول بالطريقة المعتادة أو اضبط موقع API المطلوب.
2. أغلق Codex وClaude Code وOpenCode والإضافات المرتبطة بها تماماً.
3. افتح التطبيق واختر المزود المناسب.
4. اختر **حفظ الحساب الحالي** وامنحه اسماً مثل <code>Personal</code>.
5. سجّل الدخول بالحساب الثاني أو اضبط موقع API آخر.
6. أغلق التطبيقات مرة أخرى واحفظه باسم مثل <code>Work</code>.
7. اختر ملفاً محفوظاً متى أردت التبديل.

يفحص التطبيق العمليات قيد التشغيل قبل تعديل الملفات. إذا بقي شيء مفتوحاً،
يطلب إغلاقه ولا يجري أي تغيير.

إذا تغيّر الحساب الحالي منذ حفظه، يطلب التطبيق تأكيداً. وإذا كان حساباً آخر
فعلاً، فاحفظه أولاً كملف تعريف جديد.

## ملفات التعريف والإعدادات

- **إعادة التسمية:** انقر نقراً مزدوجاً على اسم ملف التعريف.
- **الحذف:** استخدم زر سلة المهملات. تُحذف اللقطة المحلية المشفرة فقط؛ لا يُحذف
  الحساب ولا يتم تسجيل الخروج.
- **آخر تحديد:** يوضح آخر ملف فعّله التطبيق.
- **لقطة تالفة:** تُخفى اللقطة المفقودة أو غير المقروءة، بينما تبقى الملفات السليمة متاحة.
- **المظهر واللغة:** يُحفظان للمستخدم الحالي في Windows.
- **البدء مع Windows:** اختياري وللمستخدم الحالي فقط.
- **التحقق من التحديثات:** لا يعمل إلا عند النقر، بلا تنزيل أو تثبيت تلقائي.

## الخصوصية والأمان

- تُشفّر ملفات التعريف باستخدام Windows DPAPI للمستخدم الحالي.
- لا تُعرض بيانات الاعتماد ومفاتيح API ولا تُكتب في سجلات التطبيق.
- تُحفظ الملفات في <code>%LOCALAPPDATA%\CodingAgentAccountSwitcher</code>.
- يقلل استبدال الملفات المحمي والاسترداد من خطر التغيير الجزئي.
- لا يرسل التطبيق بيانات اعتماد أو أسماء ملفات أو معرّفات جهاز أو قياساً عن بُعد.
- قد تخضع حسابات العمل لسياسة المؤسسة؛ احصل على موافقة قبل حفظ نسخة دخول محلية إضافية.

اقرأ [SECURITY.md](SECURITY.md) قبل الإبلاغ عن مشكلة أمنية.

## القيود

- قد يتطلب تسجيل الخروج من جهة المزود أو انتهاء الرمز أو SSO أو MFA أو سياسة
  المؤسسة تسجيل دخول عادياً من جديد.
- لا ينقل التطبيق الاشتراكات ولا يضمن بقاء تسجيل الدخول دائماً.
- يدعم حالياً Windows 10 وWindows 11 x64 فقط.

## البناء من المصدر

يتطلب Windows و.NET SDK 8.0.400 أو feature band أحدث من .NET 8.

~~~powershell
dotnet restore CodingAgentAccountSwitcher.sln
dotnet test CodingAgentAccountSwitcher.sln --configuration Release
dotnet run --project .\src\CodingAgentAccountSwitcher.App\CodingAgentAccountSwitcher.App.csproj
~~~

كل push إلى <code>main</code> يجعل GitHub Actions يعيد بناء مثبّت وتطبيق
<code>latest</code> المحمول المتجدد.
