Codex, Claude Code और OpenCode के सहेजे गए खातों या API साइट सेटअप के बीच
आसानी से बदलने के लिए एक सरल Windows ऐप।

यह केवल प्रोफ़ाइल में सहेजी गई खाता जानकारी और समर्थित API सेटिंग बदलता है।
MCP सर्वर, स्किल, प्लगइन, प्रोजेक्ट सेटिंग और इतिहास अपनी जगह बने रहते हैं।

> [!IMPORTANT]
> यह एक अनौपचारिक सामुदायिक प्रोजेक्ट है। इसका OpenAI, Anthropic, Apple या
> OpenCode प्रोजेक्ट से संबंध नहीं है। यह सब्सक्रिप्शन ट्रांसफ़र नहीं करता,
> साइन-इन की शर्तों को नहीं टालता और संगठन की नीति को नहीं बदलता।

## डाउनलोड

वर्तमान संस्करण
[नवीनतम रिलीज़](https://github.com/zzz1999/coding-agent-account-switcher/releases/latest)
से प्राप्त करें:

- **इंस्टॉलर:** <code>CAAS-vX.Y.Z-Setup-x64.exe</code>
- **पोर्टेबल ऐप:** <code>CAAS-vX.Y.Z-Portable-x64.exe</code>
- **चेकसम:** हर executable के लिए संबंधित SHA-256 फ़ाइल दी जाती है

इंस्टॉलेशन केवल वर्तमान उपयोगकर्ता के लिए है, एडमिन अधिकार नहीं माँगता और आपकी
पसंद के बिना **Windows के साथ शुरू करें** चालू नहीं करता। वर्तमान बिल्ड साइन
नहीं हैं, इसलिए Windows SmartScreen चेतावनी दिखा सकता है।

## मुख्य सुविधाएँ

- निजी, कार्य और API साइट प्रोफ़ाइल स्पष्ट नामों के साथ सहेजें।
- कुछ क्लिक में Codex, Claude Code और OpenCode खाते बदलें।
- समर्थित API पते, कुंजियाँ और प्रदाता रूटिंग सही प्रोफ़ाइल के साथ रखें।
- डबल-क्लिक से प्रोफ़ाइल का नाम बदलें या स्थानीय स्नैपशॉट हटाएँ।
- स्विच के बाद सक्रिय प्रोफ़ाइल नाम की साफ़ पुष्टि देखें।
- संबंधित ऐप खुले रहने पर स्विच रोकें।
- 12 अंतर्निहित भाषाओं में से किसी एक का उपयोग करें।
- लाइट/डार्क थीम और भाषा अगली बार भी बनाए रखें।
- उसी Windows लॉगिन सेशन में ऐप दोबारा खोलने पर नई विंडो बनाने के बजाय मौजूदा
  विंडो को रीस्टोर करके सामने लाया जाता है।
- वैकल्पिक Windows स्टार्टअप और मैनुअल अपडेट जाँच का उपयोग करें।

सारा डेटा कंप्यूटर पर रहता है। ऐप में एनालिटिक्स या टेलीमेट्री नहीं है।

## समर्थित ऐप

| ऐप | क्या बदलता है | क्या नहीं बदलता |
| --- | --- | --- |
| Codex | लॉगिन और चुने हुए API प्रदाता की कनेक्शन सेटिंग | मॉडल, समीक्षा/रीज़निंग विकल्प, फ़ीचर, MCP, स्किल, सेशन, इतिहास और अन्य सेटिंग |
| Claude Code | लॉगिन और समर्थित API पता/कुंजी सेटिंग | प्लगइन, MCP, प्रोजेक्ट, इतिहास और अन्य सेटिंग |
| OpenCode | सहेजा गया लॉगिन और समर्थित प्रदाता/मॉडल सेटिंग | प्रोजेक्ट कॉन्फ़िगरेशन और अन्य सेटिंग |

केवल इस प्रोजेक्ट द्वारा समर्थित खाता फ़ील्ड बदले जाते हैं। सटीक सूची के लिए
[आर्किटेक्चर](docs/ARCHITECTURE.md) देखें।

## जल्दी शुरू करें

1. सामान्य रूप से साइन इन करें या उपयोग की जाने वाली API साइट सेट करें।
2. ऐप खोलें और सही प्रदाता चुनें।
3. **वर्तमान खाता सहेजें** चुनें और <code>Personal</code> जैसा नाम दें।
4. दूसरे खाते में साइन इन करें या दूसरी API साइट सेट करें।
5. उसे <code>Work</code> जैसे नाम से सहेजें।
6. खाता बदलते समय संबंधित ऐप पूरी तरह बंद करें, फिर सहेजी गई प्रोफ़ाइल चुनें।

खाता सहेजते समय संबंधित ऐप खुला रह सकता है। बदलने से पहले ऐप चल रही प्रक्रियाएँ
जाँचता है। कुछ खुला हो तो पहले उसे बंद करने को कहता है और कोई बदलाव नहीं करता।

यदि सहेजने के बाद वर्तमान खाता बदल गया है, ऐप पुष्टि माँगता है। यदि वह वास्तव
में दूसरा खाता है, तो पहले उसे नई प्रोफ़ाइल के रूप में सहेजें।

## प्रोफ़ाइल और सेटिंग

- **नाम बदलें:** प्रोफ़ाइल नाम पर डबल-क्लिक करें।
- **हटाएँ:** ट्रैश बटन उपयोग करें। केवल स्थानीय एन्क्रिप्टेड स्नैपशॉट हटता है;
  खाता नहीं मिटता और साइन आउट नहीं होता।
- **अंतिम चयनित:** ऐप द्वारा सबसे हाल में सक्रिय की गई प्रोफ़ाइल।
- **खराब स्नैपशॉट:** गुम या न पढ़ा जाने वाला स्नैपशॉट छिप जाता है; सही प्रोफ़ाइल उपलब्ध रहती हैं।
- **थीम और भाषा:** वर्तमान Windows उपयोगकर्ता के लिए याद रखी जाती हैं।
- **Windows के साथ शुरू करें:** वैकल्पिक और केवल वर्तमान उपयोगकर्ता के लिए।
- **अपडेट जाँचें:** केवल क्लिक करने पर चलता है; स्वतः डाउनलोड या इंस्टॉल नहीं करता।

## गोपनीयता और सुरक्षा

- प्रोफ़ाइल वर्तमान Windows उपयोगकर्ता के लिए Windows DPAPI से एन्क्रिप्ट होती हैं।
- क्रेडेंशियल और API कुंजियाँ दिखाई या ऐप लॉग में लिखी नहीं जातीं।
- प्रोफ़ाइल <code>%LOCALAPPDATA%\CodingAgentAccountSwitcher</code> में रहती हैं।
- सुरक्षित फ़ाइल प्रतिस्थापन और रिकवरी अधूरे बदलाव का जोखिम कम करते हैं।
- ऐप क्रेडेंशियल, प्रोफ़ाइल नाम, डिवाइस पहचान या टेलीमेट्री नहीं भेजता।
- कार्य खाते संगठन की नीति के अधीन हो सकते हैं; अतिरिक्त स्थानीय लॉगिन कॉपी
  सहेजने से पहले अनुमति लें।

सुरक्षा समस्या बताने से पहले [SECURITY.md](SECURITY.md) पढ़ें।

## सीमाएँ

- प्रदाता की ओर से लॉगआउट, टोकन समाप्ति, SSO, MFA या संगठन नीति फिर से सामान्य
  साइन-इन माँग सकती है।
- मौजूदा Codex बातचीत उस प्रदाता से जुड़ी रहती है जिसका उपयोग उसे बनाते समय हुआ
  था। प्रदाता बदलने के बाद नई बातचीत शुरू करें, या पुरानी बातचीत जारी रखने के लिए
  मूल प्रदाता पर वापस जाएँ।
- ऐप सब्सक्रिप्शन ट्रांसफ़र नहीं करता और स्थायी लॉगिन की गारंटी नहीं देता।
- अभी केवल Windows 10 और Windows 11 x64 समर्थित हैं।

## स्रोत से बिल्ड

Windows और .NET SDK 8.0.400 या नई .NET 8 feature band आवश्यक है।

~~~powershell
dotnet restore CodingAgentAccountSwitcher.sln
dotnet test CodingAgentAccountSwitcher.sln --configuration Release
dotnet run --project .\src\CodingAgentAccountSwitcher.App\CodingAgentAccountSwitcher.App.csproj
~~~

<code>main</code> पर हर push के बाद GitHub Actions नया versioned Release प्रकाशित
करता है। इंस्टॉलर और पोर्टेबल ऐप केवल सबसे नए Release में रहते हैं।
